# Patient Admission Portal (prototype)
ASP.NET Core MVC (.NET 8), in-memory data, Bootstrap 5 via CDN.

    dotnet run

Open the URL printed in the console (e.g. http://localhost:5000).

Features: submit admission request, search/filter list, view details, assign bed & admit, discharge.
Next steps: EF Core + SQL Server, authentication/roles, audit logging, HIPAA-style data protection.
